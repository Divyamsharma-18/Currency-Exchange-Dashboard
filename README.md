## 🧭 What’s This Project?

A sleek, responsive currency-converter tool designed to make your life easier (and look good doing it).
Whether you’re converting USD to INR, checking EUR to GBP, or just playing around with rates, this dashboard gives you a clean interface, smooth functionality, and the kind of visual polish you expect in a premium app.

---

## ✨ Features You’ll Notice

* 🔢 **Currency conversion** — pick your currencies, enter an amount, get your result fast
* 🔄 **Swap functionality** — flip base and target currencies with just a click (if implemented)
* 📊 **Clean UI with design care** — soft colours, clear typography, intuitive controls
* 📱 **Fully responsive design** — this dashboard looks great on phones, tablets, and desktops
* 🛠 Built with simple, clear code: HTML + CSS + JavaScript — no excess, just elegance

---

## 🧠 Tech Stack

| Technology     | Role                                                                      |
| -------------- | ------------------------------------------------------------------------- |
| **HTML**       | Structure: inputs, selectors, results display                             |
| **CSS**        | Styling: layout, responsiveness, visual polish                            |
| **JavaScript** | Logic: fetching rates (if using API), performing conversions, updating UI |
